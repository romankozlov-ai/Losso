## Технічний стек

| Частина | Технологія | Чому |
|--------|-------------|------|
| Фреймворк | **Next.js** | SSR/SSG — сторінки віддаються як HTML, краще індексація в Google і коректна робота лендингів з Google Ads |
| Стилі | **Tailwind CSS** | Швидка верстка, консистентний UI |
| Маршрутизація | **Next.js App Router** | Файлова маршрутизація: `app/`, сторінки автоматично за маршрутами |
| Дані (на старті) | **JSON / локальні дані** | Каталог у `data/` або в компонентах; пізніше — API або CMS |
| Форми (замовлення, контакт) | **Server Actions або API route** | Відправка на пошту або сервіс (Formspree, Telegram Bot тощо) |

Мова: у `layout` встановити `lang="uk"`, весь контент українською. Для Google Ads важливо: семантична розмітка, унікальні title/description на сторінках, швидке завантаження.

## Структура проекту (Next.js)

```
Losso/
├── README.md
├── package.json
├── next.config.js
├── tailwind.config.js
├── public/              # статичні файли (favicon, зображення)
└── app/
    ├── layout.jsx       # кореневий layout: lang="uk", Header, Footer
    ├── page.jsx         # головна
    ├── globals.css      # Tailwind
    ├── catalog/         # каталог і категорії
    ├── product/[id]/    # картка товару
    ├── cart/            # кошик
    ├── delivery/        # доставка та оплата
    ├── contacts/        # контакти
    └── ...
├── components/          # Header, Footer, ProductCard, Layout тощо
└── data/                # категорії, товари (JSON або js)
```

**Сторінки (маршрути):**
- `/` — головна (категорії, акції, контакти)
- `/catalog` — каталог (фільтри за категоріями)
- `/catalog/[category]` — товари категорії
- `/product/[id]` — картка товару
- `/cart` — кошик
- `/delivery` — доставка та оплата
- `/contacts` — контакти

Усі сторінки — з унікальними `<title>` та `<meta name="description">` для SEO та реклами в Google.

## Локальний запуск (якщо localhost не відкривається, помилка -102)

Помилка **-102** (Connection refused) часто буває в WSL: браузер у Windows не бачить сервер у WSL.

**1. Запустіть сервер у терміналі (в папці Losso):**
```bash
cd /home/user/projects/Losso
npm run dev
```
Дочекайтесь рядка на кшталт: `Ready in ...` та порту (наприклад `localhost:3000` або `3001`).

**2. Спробуйте відкрити сайт так:**
- У **Cursor / VS Code**: панель «Ports» (View → Ports) — знайдіть порт 3000 або 3001 і натисніть «Open in Browser». Так браузер часто підключається коректно.
- Або в терміналі WSL виконайте:
  ```bash
  hostname -I | awk '{print $1}'
  ```
  і відкрийте в браузері Windows: `http://ОТРИМАНИЙ_IP:3001` (підставте порт, який показав `npm run dev`).

**3. Якщо Node встановлений у Windows** — можна запускати проект з PowerShell/CMD з папки проекту (шлях до папки Losso у WSL з Windows зазвичай: `\\wsl$\Ubuntu\home\user\projects\Losso`):
```bash
cd \\wsl$\Ubuntu\home\user\projects\Losso
npm run dev
```
Після цього `http://localhost:3000` у Windows зазвичай працює.

## Git і деплой (Vercel)

- **Робоча гілка:** тільки **`master`**. Default branch на GitHub — `master`.
- **Деплой:** після `git push origin master` Vercel автоматично збирає й публікує сайт.
- **Що робити:** завжди працюй у гілці `master`, потім:
  ```bash
  cd /home/user/projects/Losso
  git checkout master
  git add .
  git commit -m "опис змін"
  git push
  ```
- **Важливо:** у Vercel для проекту Losso має бути **Production Branch = master** (Settings → Git). Якщо там було `main` — зміни на `master`, інакше деплой не оновиться.

## Наступні кроки

1. Ініціалізувати проект (Next.js + Tailwind), у `layout` встановити `lang="uk"`.
2. Зробити макет: Header (лого, навігація, кошик), Footer (контакти, посилання).
3. Головна сторінка: блок категорій, коротко про магазин, контакти; задати metadata для SEO/Google Ads.
4. Каталог і сторінки категорій з даних у `data/`, унікальні title/description для кожної.
5. Сторінка товару з metadata, кошик (локальний стан або localStorage).
6. Сторінки «Доставка та оплата» та «Контакти», форма зворотного зв’язку.
7. При потребі — підключити відправку замовлень (пошта / Telegram тощо). Після публікації — налаштування Google Ads (посилання на лендинги, теги тощо).
